A new TINY coding agent model dropped quietly: Omnicoder-9B.

It’s built on top of Qwen3.5-9B’s hybrid architecture and trained on 425k+ real agentic coding trajectories (tool use, terminal ops, multi-step fixes, the kind of things engineers actually do).

I ran it locally with the Pi coding agent.

On a MacBook M1 Max (32GB), through llama.cpp.

And the results were… surprisingly good.

Not "a full feature in one shot" good.

But very solid at small, well-described actions like refactors, tiny logic pieces, and structured edits. The kind of work that makes up most of real coding sessions.

The most interesting part for me is completions.

Cursor still has some of the strongest completions out there. But models like this start to make local completion feel realistic. If you can feed enough context and avoid server latency or usage credits.

Still early, but promising.

I’ll keep experimenting.
