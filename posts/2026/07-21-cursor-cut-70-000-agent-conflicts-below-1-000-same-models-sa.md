Cursor cut 70,000 agent conflicts below 1,000.

Same models. Same four-hour budget. The old Grok 4.5 swarm made 68,000 commits in two hours, then collected more than 70,000 merge conflicts. Its hottest file was touched by 1,173 agents. The new swarm's hottest file saw 47 conflicts, and every new configuration later passed the whole held-out SQLite suite.

The model bill tells the same story. Four mixes produced similar quality, but cost ran from $1,339 to $10,565. The cheapest split put frontier intelligence into planning and cheaper models on execution.

If you are building parallel agents, stop treating model choice as the architecture. Define who owns a decision, how work splits, and who resolves collisions before you add another worker. How are you measuring agent coordination?
